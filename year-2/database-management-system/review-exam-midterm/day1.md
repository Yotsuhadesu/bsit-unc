# Session 1
## Data vs Information vs Knowledge
- Data - raw facts
- Information - data with context
- Knowledge - information with experience and insight
## Metadata (Data about Data)
- Metadata - data that describes other data
- Example: date created, file size, file type, VARCHAR, INT, etc.
## Database
- Database - large, organized collection of related data that is shared and used in an organization's operations
- Holds two things: 
    - End-User Data - the actual data that people work on
    - Metadata - data about the end-user data
- Example: POS, Banking and ATMs, Reservation
## DBMS
- Database Management System - software that lets you create, maintain, and control a database
- Apps talk to a DBMS using SQL (Structured Query Language)
    - SQL Two Parts:
        - Data Definition Language (DDL) - create structure
        - Data Manipulation Language (DML) - work with the data inside
## Controlled Access in a DBMS
1. Security
2. Integrity
3. Backup and Recovery
4. Catalog
## DBMS Products
1. Commercial (paid)
2. Open Source (free)
# Session 2
## File-Based System vs Database System Approach
- File-Based System - each department keeps its own files and manages its own data
- Database System Approach - files are stored in a centralized, shared database
## Database Approach
- Advantages:
    - Consistemcy
    - Control over Reduandancy
    - Integrity
    - Sharing
    - Centralized control
    - Greater Security
    - Multiple Views
    - Increased concurrrency
- Disadvantages:
    - Larger Cost
    - Greater Complexity
    - Cost
    - Bigger Impact of Failure
    - Performance
## SDLC

    3. Designing
    4. Building
    5. Testing
    6. Deployment
    7. Maintenance
