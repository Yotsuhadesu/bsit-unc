# CSS and its Selectors

## CSS vs HTML
- A webpage consists of HTML and CSS.
- HTML - the content of the webpage
- CSS - the apperance of the content and the webpage itself

## Three Parts
1. Selector
2. Property
3. Value

## 3 Ways to Apply
1. Inline CSS
    - Location: Inside the tag of the HTML element using the `style` attribute
2. Internal CSS
    - Location: Inside a `<style>` block in the `<head>` of the HTML file
3. External CSS
    - Location: A separate .css file that is linked in the `<head>` of the HTML file
- Priority Order: !important > Inline > Internal = External > Browser Default
