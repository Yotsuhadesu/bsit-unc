# Concepts
1. Display
    - inline - one liner, like a sentence
    - block - takes the whole row
    - inline-block - sits on the same line but has a proper box
    - none - hides the element
2. Flex
    - give one instruction to flex-container, and it will implement it to its children
    - flex-container - the parent container
    - flex-items - the child
3. justify-content and align-items
    - justify-content - horizontally
    - align-items - vertically
4. Position
    - control where the element sits
    - static - default, top, left, right, bottom doesn't do anything to it
